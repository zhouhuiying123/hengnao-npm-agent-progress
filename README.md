## 项目一句话

在恒脑低代码画布上搭建一条 npm 包投毒风险初筛工作流（2026-11-11 实际画布结构）：
**开始 → flash_llm（四意图分类+参数提取）→ 校验（Python 确定性校验）→ RAG推理决策（判定 + 报告生成）→ 独立检索工具（node3）→ MCP 外部 npm 信息（node4/node5）→ 解析（node6，待接校验器）→ 结束（渲染 `node0.report_text`）**。
旁支：无关问题 → 固定输出（node8 欢迎语）→ 结束；node7 已废弃。
